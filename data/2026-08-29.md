### [1] [Constraint-Aware Physics-Informed Neural Networks for Static Shape Estimation of Co-Manipulative Continuum Robots](https://arxiv.org/abs/2608.26273)
*Rana Danesh,Pari Qarehdaghi,Farrokh Janabi-Sharifi*

Main category: cs.RO

TL;DR: 本文提出一种约束感知的物理信息神经网络（PINN），用于肌腱驱动连续体机器人的静态形状估计。该方法融合投影静态平衡残差和几何闭环残差，在有限且含噪的训练数据下显著优于纯数据驱动ANN，并在仿真和实验中均验证了精度、物理一致性和计算效率。


<details>
  <summary>Details</summary>
Motivation: 协同操作连续体机器人（CCR）的静态形状估计困难，因为连续体臂与被操作柔性物体构成闭链，必须同时满足静态平衡和几何闭环约束。传统迭代求解器虽准确但计算昂贵，纯数据驱动方法在数据有限、含噪时精度不足且不保证物理一致性。

Method: 采用几何变量应变公式构建肌腱驱动CCR模型，设计约束感知的PINN，融合两类物理约束：投影静态平衡残差（projected static equilibrium residual）和构型级几何闭环残差（configuration-level geometric residual），联合训练网络以满足力学控制和闭环几何。实验阶段通过实验数据微调提升实际性能。

Result: 在140个样本和50%标签噪声条件下，PINN相对ANN将构型误差、平衡残差、闭环残差分别降低67.88%、67.35%、88.06%。全数据集下相对构型误差仅0.1597%，推理时间0.1773ms（对比迭代非线性求解器的17.97s）。实验微调将标记RMSE从2.657mm降至0.497mm，R²从-0.788提升至0.937。

Conclusion: 约束感知PINN能够实现准确、物理一致且计算高效的闭链CCR静态形状估计，验证了将力学约束嵌入神经网络以处理闭环连续体机器人问题的有效性。

Abstract: Static shape estimation of co-manipulative continuum robots (CCRs) is challenging because the continuum arms and manipulated flexible object form a closed chain that must satisfy both static equilibrium and geometric loop-closure constraints. This paper presents a constraint-aware physics-informed neural network (PINN) for static shape estimation of a tendon-driven CCR modeled using the geometric variable strain formulation. The proposed method incorporates a projected static equilibrium residual and a configuration-level geometric residual to enforce the governing mechanics and closed-chain geometry. In simulation, the PINN is compared with a purely data-driven artificial neural network (ANN) under limited and noisy training data. With 140 samples and 50% label noise, the PINN reduces the relative configuration error, equilibrium residual, and closed-chain residual by 67.88%, 67.35%, and 88.06%, respectively. Using the full dataset, the PINN achieves 0.1597% relative configuration error with an inference time of 0.1773 ms, compared with 17.97 s for an iterative nonlinear solver. Experimental fine-tuning reduces the marker RMSE from 2.657 mm to 0.497 mm and increases R2 from -0.788 to 0.937. These results demonstrate accurate, physically consistent, and computationally efficient static shape estimation of closed-chain CCRs.

### [2] [Dispersive Forward Tree Search for Optimal Control: Coverage, Complexity, and Computation](https://arxiv.org/abs/2608.26314)
*Shashank A. Deshpande,Jonathan P. How*

Main category: cs.RO

TL;DR: 本文提出DFT*（Dispersive Forward Tree search），一种基于前向传播的动力学规划器，针对微分平坦非线性系统提供确定性有限样本近最优性保证。通过构造局部离散控制命令的前向树，DFT*在认证树规模内包含近最优轨迹，并采用成本条件支配剪枝将树规模从指数缩减为多项式。在单轮车、拖车和四旋翼上实现高效采样器，展现出比现有最先进规划器更优的求解质量，并支持并行硬件加速及动态环境中的实时重规划。


<details>
  <summary>Details</summary>
Motivation: 基于转向的规划器需要求解状态到状态的边界值问题，这对非线性平台往往不可行；前向传播虽规避了转向需求，但缺乏有限样本行为的理论刻画，且实际实现性能不佳。本文旨在开发一种既有确定性有限样本近最优性理论保证、又能在实践中高效运行的前向传播动力学规划器。

Method: 在微分平坦非线性系统类中，证明前向的局部离散控制命令树在认证规模内含近最优轨迹；为控制仿射系统构造离散命令集的一般机制；证明无成本条件的轨迹覆盖需求指数级树规模，并提出成本条件支配剪枝实现多项式规模；将算法实现为广度优先的前向树扩展（DFT*），设计针对单轮车、拖车、四旋翼的高效离散采样器，并支持并行硬件。

Result: DFT*在嵌入级处理器上与最先进动力学规划器相比，求解质量持续具有竞争力且经常大幅更优，随并行计算扩展而进一步加速；在动态环境中的滚动时域部署实现了实时规划。

Conclusion: 前向传播型规划器可以通过理论驱动的命令集设计与成本条件剪枝，同时获得近最优性保证与实用高效性能，为非线性系统的运动规划提供了新的可行性路径。

Abstract: Steering-based planners require solutions to state-to-state boundary value problems, which can be inaccessible for nonlinear platforms. Forward propagation evades the steering requirement, but the finite-sample behavior of the associated planners remains uncharacterized and their implementations underperform in practice. This paper develops a propagation-based kinodynamic planner with deterministic finite-sample near-optimality guarantees. We work within the large class of differentially flat nonlinear systems and show that a forward tree of locally dispersive control commands contains a near-optimal trajectory at a certified tree size. We provide a general mechanism to construct dispersive command sets for control-affine systems, which are necessary to implement the search algorithm prescribed by the theory. We show that covering the certified trajectory class irrespective of cost provably demands a tree exponentially sized in the problem horizon, and present a cost-conditioned dominance pruning procedure that retains near-optimality at a tree size polynomial in the horizon. We implement the resulting search algorithm, Dispersive Forward Tree search (DFT*), as breadth-first expansion of the forward tree, which maps naturally onto parallel hardware. We design efficient dispersive samplers for the unicycle, the trailer car, and the quadrotor and evaluate challenging planning tasks for these platforms. DFT* delivers consistently competitive and often substantially better solution quality than state-of-the-art kinodynamic planners at comparable solution times on embedded-tier processors, accelerating further as parallel compute is scaled. We also implement DFT* in a receding-horizon loop to demonstrate real-time planning in dynamic environments at embedded-tier compute budgets.

Abstract: Autonomous robots performing laboratory tasks depend on 3D reconstruction pipelines that can turn raw camera streams into actionable object representations within the latency budget of a physical control loop. ### [4] [Memory Anchors for Continual Robot Learning](https://arxiv.org/abs/2608.26545)
*Maximilian Du,Zhanyi Sun,Chen Xu,Paarth Shah,Masha Itkina,Shuran Song*

Main category: cs.RO

TL;DR: 本文提出"Memory Anchors"概念：在机器人策略持续学习场景下，仅少量旧任务经验对维持已有行为至关重要。这些锚点出现在新旧任务表征发生坍缩（观察相似但动作冲突）的区域。仅剔除10%的锚点就导致在LIBERO基准上灾难性遗忘增加4.5倍以上；而向回放缓冲区富集锚点可将高冲突任务遗忘降低63%，并在真实机器人上实现两个任务序列的持续学习。


<details>
  <summary>Details</summary>
Motivation: 机器人在真实环境中部署需要持续学习新任务而不遗忘已有行为。常用的回放缓冲区随机采样所有旧经验，但作者观察到只有一小部分旧经验对锚定过去性能至关重要，随机采样忽略了这些关键样本，导致灾难性遗忘。

Method: 定义并识别Memory Anchors：在新任务观测的表征与旧任务观测发生坍缩（表征重叠但需要冲突动作）的区域中，对应的旧任务数据即为Memory Anchors。通过分析表征空间的坍缩位置来定位这些关键经验，并将其纳入回放缓冲区以增强持续学习效果。

Result: 1) 剔除10%的Memory Anchors后，LIBERO基准套件上灾难性遗忘增加4.5倍以上；2) 向回放缓冲区富集Memory Anchors可将高冲突任务的遗忘降低63%；3) 在真实机器人上成功实现了两个任务序列的持续学习。

Conclusion: Memory Anchors是持续学习中回放缓冲区的关键组成部分，超越传统随机采样策略。基于表征坍缩区域识别这些锚点，可以有效防止破坏性覆盖旧任务知识，显著提升机器人策略在真实环境中的持续学习能力。

Abstract: Robot policies deployed in the wild should have the capability to continually learn new tasks without forgetting existing behaviors. A common approach to combat such catastrophic forgetting is to train on new task data with a replay buffer of previously learned task data. Although this buffer is commonly sampled randomly from all prior experiences, we show that a small set of these experiences contributes greatly in anchoring past performance. We call these experiences Memory Anchors. We identify Memory Anchors in regions where representations of new-task observations collapse onto those of old-task observations even though the tasks require conflicting actions, like when a familiar object must be manipulated in a new way. Rehearsing old data in this region plays a key role in preventing destructive overwriting of past task knowledge, serving as this critical Memory Anchor role. Excluding only 10% Memory Anchors before sampling the buffer leads to more than a 4.5x increase in catastrophic forgetting on the LIBERO benchmark suites. Conversely, enriching the replay buffer with Memory Anchors can decrease high-conflict task forgetting by 63% and enables successful continual learning of two task sequences on a real robot. Videos and additional visualizations can be found at https://robot-adaptation.github.io/MemoryAnchors
